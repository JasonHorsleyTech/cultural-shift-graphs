## Step 2: Enrichment

Check if `projects/sexual-language-index/data/enriched/km.jsonl` already exists with adequate coverage (≥ 80% of dump word count).
If it does, skip to Step 3.

**Do NOT run `enrich-batch.sh`.** Enrich the words directly using your own knowledge:

1. Read `projects/sexual-language-index/data/dump/km-words.txt` — parse every line starting with `- ` to extract the word list.
   For lines like `- 阴茎 (yīnjīng)`, the term is `阴茎` and `yīnjīng` is the romanization.
2. Read `projects/sexual-language-index/data/registry/concepts.json` — canonical concept registry
   (582 slugs). Match each word to a registry slug when possible.
3. For each word, write one JSONL record to `projects/sexual-language-index/data/enriched/km.jsonl`.
   **Process in batches of 100 words** — write each batch to disk (append) before continuing.
   If the file already has partial records, check the count and skip words already covered.

### JSONL schema (one flat record per line, no prose, no code fences):

```
{"term":"...","lang":"km","script":"...","romanization":"...","category":"...","subcategory":"...","concept":"...","is_novel_concept":false,"register":"...","crude":N,"technical":N,"recognition_pct_current":N,"recognition_pct_peak":N,"peak_year":null,"regional":null,"definition":"...","english_term":"...","english_translation_quality":"direct|approximate|none","notes":""}
```

**Field values:**

- `script`: `"latin"` | `"hans"` | `"hant"` | `"cyrl"` | `"arab"` | `"deva"` | `"hebr"` | `"kana"` | `"mixed_jp"` | `"hang"` | `"thai"` | `"ethi"` | `"mymr"` | `"khmr"` | `"beng"` | `"taml"` | `"guru"`
- `category`: `"organs"` | `"acts"` | `"fluids_states"` | `"desire_arousal_descriptors"` | `"identities_orientations"` | `"insults"` | `"sex_work_pornography"` | `"reproductive_contraceptive"` | `"kink_paraphilia"` | `"euphemisms_idioms"` | `"archaic_literary"` | `"internet_subculture"` | `"religious_moral_status"` | `"honor_shame_economy"` | `"third_gender_roles"` | `"ritual_spiritual_practice"`
- `register`: `"clinical"` | `"slang_neutral"` | `"slang_crude"` | `"euphemism"` | `"dated_slang"` | `"archaic"` | `"literary"` | `"subculture"` | `"moral_religious"` | `"loanword"` | `"classical_specialized"`
- `english_translation_quality`: `"direct"` | `"approximate"` | `"none"`
- `concept`: registry slug, or new snake_case slug if `is_novel_concept: true`
- `crude` / `technical`: independent 0-100. ("coitus" → crude=5, technical=95. "fucking" → crude=85, technical=5.)
- `recognition_pct_current`: % of adult Khmer speakers who'd recognize the word in 2026
- `peak_year`: only for dated terms with a clear peak in living memory; null otherwise
- `is_novel_concept`: true ONLY for concepts with no English equivalent — use sparingly

Include slurs, crude terms, and insults without omission — the data needs them.
