# Ticket 001: Validate Female-Targeted Heartthrob List

**Type:** Validation (not character profile)
**Audience:** female-targeted
**Result file:** results/001-validate-female-targeted-list.md

## Task

Validate the locked 25 female-targeted heartthrobs in `heartthrobs.md` against multi-source aggregation across published rankings. Report findings — do NOT modify the locked list. Any swap recommendations go to Jason for review.

## Steps

1. Pull rankings from at least 5 of these source types (use what's accessible via web search):
   - Goodreads "Best Book Boyfriends" lists (multiple editions / community lists)
   - NYT romance bestseller archive / All-Time Bestseller lists
   - Cosmopolitan, Glamour, Marie Claire archives of "ultimate movie boyfriends" / "best book boyfriends"
   - BBC, Vulture, Empire "best rom-com leads" / "sexiest movie leads"
   - Romance Writers of America RITA / Vivian Award winners

2. For each of the 25 locked characters, count appearances across the source set. Note in which decade most sources place them.

3. Cross-validate with consumption proxies: book sales, box office, TV viewership.

4. Identify any character on the locked list who scores low on aggregate-list mentions. Identify any high-scoring character missing from the locked list.

5. Write the result file with:
   - The full reach-validation table (fills in `heartthrobs.md`'s pending validation columns)
   - A short list of "consider swapping" recommendations, with reasoning
   - Methodology notes (which source lists were used, how aggregation was scored)

## Constraints

- Do NOT modify `heartthrobs.md`. The list is locked. Recommendations go to Jason; he decides whether to act.
- Cap research at one ticket's worth of work — this is validation, not exhaustive cultural analysis. If a particular source isn't accessible, note it and move on.
- Generational stratification matters: a character that's iconic but only appears in modern lists might still be the right pick for an older decade. Look for decade-of-cultural-peak signal.
