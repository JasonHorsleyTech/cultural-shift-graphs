1. Pull rankings from at least 5 of these source types (use what's accessible via web search):

3. Cross-validate with consumption proxies: box office, game units shipped, TV viewership, fan-creation footprint where measurable (e.g. fan-art volume on major platforms — proxy for fantasy-object status).

4. Identify any locked character who scores low. Identify any high-scoring character missing from the locked list.

5. Write the result file with:
