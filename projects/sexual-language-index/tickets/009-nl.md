# Ticket 009: Dutch (`nl`)

## Goal

Produce two artifacts for language `nl` (Dutch):
1. `data/dump/nl-words.txt` — Pass 1 word dump (~600-1500 sexually-charged words)
2. `data/enriched/nl.jsonl` — Pass 2 enrichment (per-word metadata: crude/technical scores, recognition %, English equivalence, etc.)

## How

Run these two commands from the repo root (`/Users/jasonhorsley/code/graphable`), in order. Both scripts are idempotent and use `claude --print` to fire Sonnet calls under the hood.

```bash
bash projects/sexual-language-index/scripts/dump-language.sh nl
bash projects/sexual-language-index/scripts/enrich-batch.sh nl
```

The dump script: one Sonnet call → markdown list of sexually-charged words. Skipped if `data/dump/nl-words.txt` already exists.

The enrich script: splits the dump into 25-word batches, fires up to ~25 parallel Sonnet calls, each producing a JSONL chunk. Concatenates to the final `.jsonl` file. Skips already-done batches.

## Verifying success

After both scripts complete, check:

```bash
# Dump should have at least 200 words (lines starting with "- ")
grep -c '^- ' projects/sexual-language-index/data/dump/nl-words.txt
# Enrichment should have at least 200 records (one per JSON line)
wc -l projects/sexual-language-index/data/enriched/nl.jsonl
```

If the enrichment count is at least 80% of the dump word count, this ticket succeeded. Write a brief result file to `projects/sexual-language-index/results/009-nl.md` with:

- Word count (from dump)
- Record count (from enrichment)
- Any rate-limit or error notes from `scripts/enrich-logs/nl/`

End the result file with the literal line `<!-- COMPLETE -->`.

## If it fails

If `claude --print` calls hit rate limits (HTTP 429 — visible in `data/enriched/.tmp-nl/batch-*.raw.json` as `is_error: true`), the enrich script will exit with an empty or undersized `.jsonl` file.

**In that case, DO NOT write a result file.** The next cron tick will retry. The script's idempotency means it will skip already-completed batches and only re-attempt the failed ones.

The token budget resets:
- 4-hour rolling window: every 4 hours
- Weekly: every Friday

Patience is the strategy — let cron retry across rate-limit windows until everything completes.
