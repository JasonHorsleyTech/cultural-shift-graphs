# Ticket 026 — Tempur Sealy mattress

## Product

A Tempur-Pedic mattress (the high-end memory foam line). Replaces "Casper" because Casper is now private with stale public filings; Tempur Sealy is a clean public comparable for the mattress category.

## Parent company

Tempur Sealy International (NYSE: TPX).

## Panel

consumer

## Segment to use

**Tempur Sealy consolidated** (single mattress business). Tempur Sealy reports two segments: North America and International — use North America for cleanest single-product proxy.

## Source hierarchy

1. **Tempur Sealy FY2024 10-K** — segment reporting, advertising disclosed.
2. **Tempur Sealy investor presentations** for marketing intensity color.
3. **ISPA (International Sleep Products Association)** for mattress category data.
4. **Mattress Firm acquisition (closed 2025?)** — Tempur Sealy is acquiring Mattress Firm; check for any pro-forma disclosure that might affect FY2024 numbers.

## Specific caveats for this product

- Mattress industry is famously marketing-heavy (60-day return guarantees, financing, TV/radio).
- Tempur is the premium brand; Sealy is mid-market — different ad intensity per brand.
- Direct-to-consumer expansion (Tempur.com, Sealy.com) blurs distribution vs. retail real estate.
- Mattress Firm acquisition will change vertical integration profile if closed during measurement period — note.
- Capex moderate — foam plants, mattress assembly.
